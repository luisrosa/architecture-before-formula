# Public version history

## v1.6 — current

`v1.6` is the reconstructed manuscript *Architecture Before the Formula: Individuating Neural Architecture Beyond the Composite Map*. The public archival record is arXiv:2601.11618v3; the same scientific manuscript was submitted to JMLR on 2026-08-12.

It makes architecture individuation and composition primary, separates extensional distinction shadows from marked receiver-process identity and continuation accessibility, and uses the injective local/attention contextual witness as the main architecture-space consequence.

## v1.0 — historical public release

`v1.0` is the earlier public receiver-factorization manuscript, *Architecture Before the Formula: Receiver-Wise Factorization and the Reconstruction of Transformer Blocks*. Its PDFs, source package, checksums, tag, and release directory are retained unchanged for provenance.

Versions v1.1–v1.5 were private development milestones leading from the v1.0 public formulation to the v1.6 reconstruction; they are not presented as independent public releases.
