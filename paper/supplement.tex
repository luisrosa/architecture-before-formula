\begin{abstract}
This supplement collects quantitative bounds, edge cases, and extensions outside the main dependency spine of the v1.0 article. It includes entropy-regularized anchoring, softmax stability and score-rank approximation, structural approximation ledgers, finite-support interpolation, explicit witnesses separating the attention commitments, information accounting under aggregation, signed and normalized FFN presentations, typed local approximation, residual error propagation, and stochastic variable-successor realizations with conditional Gibbs and KL identities. None of these extensions changes the main article's architectural primitive or the dependency path to the Transformer normal form.
\end{abstract}

\paragraph{Relation to the main article.}
The main article contains the definitions and proofs required for receiver-factored architecture, interface barriers, attention, local continuation, and the canonical block. This supplement assumes that notation and compiles after the main article so cross-document references can be resolved.
